# Goal on-track/pace projection uses a trailing 3-month average, not whole-history or a separate contribution input

Monarch's "Save Up Goals" ask the user to enter a monthly contribution amount and compare it against the pace required to hit the target date. CONTEXT.md's Goal definition requires progress to be "derived from existing Transaction/Budget/Account data, not a separate input" — so PesantMoney cannot add a user-entered "monthly contribution" field. We considered deriving the actual contribution rate from the goal's entire history (simple, but slow to reflect a user who changed their savings habits, and misleading for old goals with an inactive stretch in the middle) versus a trailing 3-month average (responsive to recent behavior, consistent with how a household actually experiences "am I keeping up right now"). We chose the trailing 3-month average of realized monthly progress (Assigned-per-month for category-linked goals, net balance change for account-linked goals), compared against the required monthly pace (`(target − current progress) / months remaining`), to classify a Goal as ahead, on track, or behind. Goals with fewer than 3 months of history report an "insufficient data" state rather than a misleading extrapolation from 1-2 data points.
