# Investment accounts get holdings via import, prices via manual/file refresh — never a live market data call

Monarch values investment accounts using live prices pulled from brokerages/market data APIs. We considered adding a narrow, opt-in exception to fetch current prices over the internet, since "no online sync" was aimed at bank account linking, not stock prices. We rejected this: it breaks the project's core positioning (fully offline, no network calls at all) and adds real complexity (API keys, rate limits, provider selection) for a single feature. Instead, holdings and balances come from brokerage-exported files like any other Account, and per-ticker prices are refreshed by importing a price file or manual entry. The UI always shows the as-of date for the last price update so a stale valuation is visible, not silent.
