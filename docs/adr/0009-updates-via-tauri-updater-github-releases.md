# App updates via Tauri's built-in updater against GitHub Releases; "offline-only" scopes to financial data, not the update checker

Considered manual-download-only updates (zero network calls, ever) versus Tauri's built-in updater polling a static manifest on GitHub Releases. Chose the built-in updater for standard security-patch adoption and UX, accepting that this means the app does make an occasional network call — clarifying that this project's "offline-only" claim is about financial data and bank connectivity (no live sync, no credentials, no transaction data ever leaves the machine), not a blanket "zero network access ever." The update check can be disabled in settings for users who want literally zero network calls. GitHub Releases is static file hosting, not a backend the app's core functionality depends on.
