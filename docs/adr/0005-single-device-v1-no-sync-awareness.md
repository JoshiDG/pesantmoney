# v1 is single-device; the app is not sync-aware

Monarch's household sharing (multiple people, multiple devices, one shared budget) depends on its cloud backend, which this project explicitly doesn't have. We considered building folder-sync awareness (pointing the app at a Dropbox/Syncthing-managed folder with conflict detection) into v1, but rejected it: it adds file-locking and conflict-resolution complexity before the core single-user experience is proven out. v1 stores one local database file with no built-in sync, conflict detection, or multi-writer support — a household can copy the file between machines via their own tooling entirely at their own risk, unsupported. Multi-device support, if pursued, is a deliberate later phase requiring its own design (likely a merge/CRDT strategy), not an incremental add-on to v1's storage engine.
